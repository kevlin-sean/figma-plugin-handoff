# Figma 离线交付插件 · v1.6.0

从 Figma 导出带预览、图层属性、布局标注、切图、颜色与 JSON 的离线 HTML ZIP。查看器参考用户提供的 Sketch MeaXure 交付模板改版，使用 Figma 的实际图层数据，不需要 API Token、服务器或模型调用。

## 安装与更新

1. 在仓库根目录执行 `pnpm install` 和 `pnpm build`。`dist/manifest.json` 与插件入口 `code.js`、`ui.html`，以及交付查看器 `index.html`、`viewer.css`、`viewer.js`、`spacing.js` 都在 `dist/`。
2. Figma 桌面端 → Plugins → Development → Import plugin from manifest…，选择 `dist/manifest.json`。
3. 从 Development 菜单运行「Figma 离线交付 · Offline Handoff」。这是本地开发插件，尚未发布到 Community。
4. 更新已有安装：关闭插件，重新 `pnpm build`，再运行并确认版本 v1.6.0。改用另一目录时重新导入 `dist/manifest.json`。

`dist/` 不进入版本库。克隆后必须先构建，再导入 `dist/manifest.json`。

## 开发

需要 Node.js 22 与 pnpm 8。

| 命令 | 作用 |
|---|---|
| `pnpm build` | 用 esbuild 生成 `dist/` |
| `pnpm watch` | 监听 `src/` 并重新构建 |
| `pnpm test` | 先构建，再运行测试 |
| `pnpm typecheck` | 检查 TypeScript |

```
src/plugin/code.ts   Figma 沙箱，只读设计稿
src/ui/              插件面板
src/core/            校验、合并、去重、预览压缩
src/viewer/          打进交付包的离线查看器
scripts/build.mjs    构建
dist/                构建结果
  manifest.json      Figma 导入这个文件
  code.js            插件主线程
  ui.html            插件面板
  index.html         交付查看器
  viewer.css
  viewer.js
  spacing.js
```

改查看器后要重新构建。Figma 加载的是 `dist/`，只改 `src/viewer` 不会生效。

## 导出交付包

选择首次导出，勾选 Pages，或在 Figma 选中一个或多个 Frame / Section。填写可选的「交付包名称」，插件生成的 ZIP 基名与内部根目录保持一致；留空沿用文件名。系统保存时单独改 ZIP 名称不会重写包内目录。

设计预览默认 2×，也可选择 1× / 3×；插件已移除 PNG 切图倍率选项，切图尺寸沿用 Figma 图层 Export 设置。普通 Section 按内部画板与散落图层独立渲染，再按原位置组合；只有单张预览长边超过 8192px 才降倍率，实际倍率保存在数据中。复杂 Section 合成回退到 Figma 整区渲染。

点击生成，完成后下载 ZIP。开发解压整个文件夹，双击 index.html 即可查看，无需联网。同一 Page 保留原画板位置，不同 Page 使用独立坐标系。

## 高清预览与体积

参考用户提供的 MeaXure 模板，画板预览使用 2× 像素并按逻辑尺寸展示：例如 1440 × 900 对应 2880 × 1800 图片。插件此前默认 1×，高分屏下较容易模糊；本版默认 2×，直接导出即可。浏览器缩放超过源像素密度时仍可能变糊，原稿内低分辨率照片也不会凭空增加细节。

仅对本次新生成的预览尝试本地 WebP 无损压缩，逐像素核对后，实际 DEFLATE ZIP 项也更小才替换；不降低像素尺寸，不使用有损 JPEG / WebP。已与切图或保留资源共用的 PNG 不额外生成第二格式。每张预览只保留一份，不叠加 1× / 2× / 3×；缩略图继续复用预览，不另导一套。Section 内嵌 PNG 同样按需无损压缩，保持位置、倍率和尺寸。

部分透明、16 位、特殊 ICC / 非标准 gamma / 色彩配置、超出工作内存限额的图片保留 PNG；浏览器不支持或压缩失败也保留 PNG。压缩在 Worker 中进行，可取消。编解码器仅随插件安装，不进入开发交付包；SVG / PNG 独立切图字节不受此压缩步骤影响。

4 张参考模板 2× 图片实测：无损 WebP 与原 PNG 解码像素一致，ZIP 项减少约 49%～53%。这是样本结果，不保证所有设计稿都达到相同比例；2× 相对旧 1× 包仍可能更大，不能承诺零体积增长。单张预览超过 8192px 的既有限制仍适用。

旧交付包的 1× 图片不能通过覆盖查看器变成 2×；需用新版重新导出对应 Frame / Section。局部更新只压缩本次预览，范围外历史图片不变。

## 新版查看器

左侧三个入口：

- **页面**：切换 Page，点击缩略图定位画板；可切换「图层目录」，展开父子层级并检查任意已导出图层。缩略图复用原有预览，不额外生成整套图片。
- **切图**：SVG / PNG 筛选、搜索，范围可选当前 Page、当前画板或全部页面；显示设计尺寸、实际像素、倍率和复用数量，支持定位图层与下载。
- **颜色**：当前 Page 中使用的颜色变量、颜色样式与普通用色；显示名称、主题模式、色值、不透明度及关联图层数量。复制颜色，命名变量有 WEB code syntax 时可复制原变量表达式；定位按钮可循环查看用色图层。

右侧对照 MeaXure 原模板：240px 深色栏、12px 字号、24px 数值框，顶部切换网页 px / iOS pt / Android dp/sp，下面为图层名称、**属性、填充、边框、字体、阴影 / 模糊、代码模板、导出**。位置 X/Y 相对所属交付画板包围框原点，大小使用图层逻辑宽高；显示不透明度、圆角、颜色、描边位置和粗细、阴影偏移 / 模糊 / 扩散。数值可双击选中复制，点击色块切换 HEX / RGBA / ARGB。单位切换按 1:1 逻辑尺寸展示，不是屏幕物理像素或平台适配换算。

无可见填充、边框、字体或效果时隐藏对应模块，空原生 CSS 不补造属性；合法的 0 值保留，换层后重新计算。移除 ID、层级跳转、布局盒模型、CSS 来源说明、Layout / Position / Style 分组标题和图层 JSON 标签，完整图层信息仍保存于 data/design.json。

代码模板提供 CSS / Android / iOS 三个入口。CSS 保留 Figma getCSSAsync() 的原始属性值；另两个入口为基础 View / TextView、UIView / UILabel 属性模板，复杂渐变、多重填充、描边或阴影仍需按设计数据补充，不是整页业务代码导出。没有原生 CSS 的旧包按已保存属性推导，原生返回空对象时不推导填补。代码可双击选中或使用标题处复制按钮。

Figma 插件导出界面只保留必要选项与简短说明；选区操作仅在选区导出或局部更新时显示。导出失败明细默认收起。

左右面板可独立收起，画布底部工具栏提供全页、适合宽度、缩放、平移和标注总开关。空格 + 拖动平移，Ctrl / Command + 滚轮围绕鼠标缩放。

## 选中切图与快捷下载

选中已导出的 SVG 图标或 PNG 图片时，右侧末尾显示「导出」文件卡片，包含预览与名称；鼠标停在卡片可查看格式、倍率和实际尺寸，完整列表仍在左侧切图面板。图标内部路径在画布上优先定位所属切图；图层目录仍可单独检查内部路径。整张交付画板设置 Export 不会拦截内部图层检查。
点击画布上的图标或图片后，右侧栏底部固定显示 **Export**，列出 SVG / PNG、倍率和尺寸。点格式行切换当前文件，点 **Export** 直接下载该文件，不再新开窗口预览。左侧切图列表的「下载」同样直接保存。文件名使用图层名称，内容是导出时的原始 SVG / PNG 字节。一个图层同时有 SVG/PNG 时，初次默认 SVG；仅有 PNG 时使用 PNG。也可以「下载全部 SVG / PNG」，得到包内 `assets/resources.zip`，按 `svg/`、`png/` 分目录。按住 **Mac Option / Windows Alt** 再点格式卡片或画布上的切图，仍走浏览器原生保存。

离线 `file://` 页面读不到旁边的图片，普通链接会被浏览器预览。因此每个切图旁会有一份仅用于下载的脚本，点击时才加载，并按原字节保存，不重编码、不经过服务器。没有成功导出的资源不会生成假下载项。旧包需要重新导出后，Export 才会直接下载；只覆盖查看器文件不够。浏览器保存目录、询问保存位置等仍由用户的浏览器设置决定。

## 选中元素的大小与间距

- 点击 Frame、Group 或其他图层，只显示橙色轮廓、四角定位点与宽高数字，不自动显示间距。
- 鼠标悬停同一交付画板内的另一图层，暂时隐藏宽高，显示选中层与悬停层的边界距离；目标四边使用蓝色虚线延伸到所属画板边界。悬停不会更改选中层及右侧属性，移开后恢复宽高。
- 尺寸与距离标签仅显示数值，不带父 / 内 / Gap 等前缀，不绘制独立父级、Padding 或布局斜线。橙色 #EE6723，蓝色 #419BF9；1px 屏幕线宽、12px 屏幕字号，随缩放保持可读。标注开关可隐藏尺寸、距离及定位虚线，保留选中轮廓。
- 不跨不同交付画板或 Page 测距。旋转按选中层父坐标轴的边界测量，复杂蒙版、裁剪和非矩形轮廓为几何近似，阴影不计入边界；测量值不等同 CSS margin。
- Auto Layout 的 Padding / Gap、父子关系及混合字体分段仍保存在结构化图层数据中，精简界面不删除原数据。

## 颜色与 CSS 的来源

新版只查询导出范围内实际使用的变量与样式名称，按 ID 缓存；变量模式与当前颜色保留在所属节点的 colorBindings、fills 等数据中。局部更新不会为了补齐颜色名称而改写范围外节点。无法读取名称时保留现有色值和绑定 ID，显示未解析变量；普通颜色与命名变量分别列示，不猜测命名。

旧包仅覆盖查看器，可以按已有填充、描边、文字和效果数据生成页面用色；缺失的变量名称、样式名称、边框细节等需要新版重新导出对应范围。没有 figmaCSS 时使用已有数据推导，可推导线性渐变；复杂填充参考切图与结构化数据。原生空结果不补造 CSS。

CSS 供开发参考；变量需接入项目主题，图片占位地址需替换为交付资源路径，交互和响应式由开发实现。字体不随包分发。接口参见 [Figma 原生 CSS](https://developers.figma.com/docs/plugins/api/node-properties/#getcssasync) 与 [变量 API](https://developers.figma.com/docs/plugins/api/figma-variables/)。

## 切图、去重与失败处理

切图导出设计稿中已添加的 SVG / PNG Export。只配置 SVG 就只导出 SVG，只配置 PNG 就只导出 PNG。没有 Export 的图标会自动导出一份 SVG：逻辑边长不超过 64px 的矢量图形（组件、实例，或名称含 icon / 图标 时放宽到 96px），且子树里没有文字和图片。成组图标只导出最外层，不把内部路径拆开；父级已有 Export 时不再自动拆子图层。一排互不重叠的小图标会分别导出。大图里互相重叠的路径视为插画，不自动切图。图片仍只跟随自己的 Export 设置；JPG / PDF 不在本版范围。同一图层同一格式仅取第一条 Export；PNG 保留该条的倍率或固定宽 / 高设置，不再由插件覆盖。未指定尺寸约束时按 Figma 默认 1× 导出。预览倍率独立，不要求根画板配置 Export。SVG 仍把文字转成轮廓，字体不随包分发。

跨画板相同资源共享文件并保留所有图层关联。PNG 按实际字节核对；静态 SVG 可归一化局部引用 ID 后核对。名称相同、颜色/形状/参数不同的资源不会误合并。JSON 紧凑保存，ZIP 使用 DEFLATE 9，不降低设计预览清晰度或有损重编码。

单张切图失败继续其他切图并生成 ZIP；插件显示简短摘要，展开明细查看 Page、画板、图层 ID / 路径、格式和原始原因。无可见内容类错误会提示检查可见性、透明度、裁剪和蒙版；不会根据这一条错误断定唯一原因。失败项不创建假资源。主动取消、预览失败或导出中设计发生变化仍会中止。

失败信息和导出提示仅存在当前插件会话，不写入交付 ZIP；不生成失败清单，也不向 update-report 写入错误、警告或失败状态。局部更新时移除旧版生成的“切图失败清单.txt”，并重新生成不含错误的紧凑更新元数据，保留原 ZIP 和用户自定义文件。关闭插件后错误明细不保留。

## 局部更新已有 ZIP

1. 导入上次 ZIP，确认属于当前 Figma 文件。
2. 选中原 Frame / Section，按稳定 ID 匹配，替换整个选中子树并保留原位置。
3. 要使用本版界面，勾选「升级交付查看器」。仅需要旧包换界面时，也可备份后覆盖四个 viewer 文件。
4. 下载新 ZIP；保留原包，后续从最新包继续更新。

局部更新的粒度是整个所选 Frame / Section，不是任意按钮。重建导致 ID 改变时需重新导出。嵌套 Frame 只允许同尺寸、不透明、无圆角/阴影、开启裁剪且没有兄弟重叠的矩形覆盖；否则需更新最外层交付区域。选择范围外的节点记录保持不变，仍引用的资源保持内容，去重与清理只发生在新 ZIP。

旧 ZIP 导入上限 300MB、解压后 1GB。查看器默认保留，只有勾选升级时替换 index.html、viewer.js、viewer.css、spacing.js。

## 交付数据与维护

- data/design.json：页面、图层层级/位置、设计属性、figmaCSS、colorBindings。
- data/assets.json：切图尺寸、格式、倍率、关联图层和路径。
- data/previews.json：预览、Section 组合与局部补丁。
- data/design-data.js：离线直接加载的数据，避免 file:// 的 JSON fetch 限制。
- data/update-report.json：更新范围、资源去重与清理元数据，紧凑 JSON，不包含失败信息或日志。

v1.6.0 通过 119 项自动测试；Chrome 以原 MeaXure 预览和属性转换的测试数据验证 Group 实际点击、选中仅尺寸、悬停测距和四条画板定位虚线、缩放、面板收起、单位 / 代码模板切换、空模块恢复与数据不变。另验证 file:// 下点击 Export 直接保存原 SVG/PNG 字节、实际插件桥接生成 ZIP、默认 2×、首条 Export、失败信息不入包及离线加载。未在用户真实 Figma 客户端实机导出验收。

插件不发起网络请求，不修改或克隆原稿；Figma 自身加载云端文件仍使用其已有权限与连接。普通导出不消耗模型 token。
